1. 产品概述

定位：镋钯RaaS管理平台（内部）是面向平台运营团队的全局管理后台，负责跨租户设备监控、平台资源管理、内容审核、动作库发布与同步、以及租户生命周期管理。

与租户平台的关系：内部平台是"平台方"视角，拥有全局只读监控权 + 平台资源管理权 + 审核权 + 系统管理权；租户平台是"租户方"视角，负责自有设备/任务/脚本的日常运营。两者通过"审核流程"和"动作库同步"形成业务闭环。

核心业务闭环：
① 租户上传素材/知识库 → ② 内部平台AI审核 → ③ 命中风险转人工复审 → ④ 审核通过转为可用 / 驳回通知上传方
⑤ 内部平台创建原子动作组合 → ⑥ 发布并同步给租户 → ⑦ 租户在脚本编辑器中引用

3. 设备总览 P0

3.1 功能说明

全局掌握所有设备的运行状态与地理分布，支持地图缩放查看省/市/区/街道级别的设备分布，点击标记查看区域详情。

3.2 统计卡片

指标说明示例值
设备总数平台所有设备总量，含较上月增量24（↑ +3）
运行中当前在线设备数及在线率18（在线率 75%）
故障/告警处于故障状态的设备数2（需处理）

3.3 地图分布

  • 地图引擎：Leaflet 1.9.4 真实地图，支持滚轮缩放
  • 过滤：全部 / 在线 / 离线 三态过滤
  • 标记颜色：绿色=全部在线、橙色=部分离线、红色=全部离线
  • 区域面板：点击地图标记弹出右侧区域统计面板，展示该区域设备明细
  • 底部提示：支持滚轮缩放查看省/市/区/街道级别的设备分布

3.4 操作逻辑

1
页面加载时初始化Leaflet地图，渲染所有设备标记
2
点击过滤按钮（全部/在线/离线），重新渲染符合条件的标记
3
点击地图标记，弹出区域统计面板，显示区域名称和设备列表
4
点击"查看设备列表 →"跳转到设备列表页

4.4 绑定 / 解绑操作

查看详情打开设备详情弹窗，查看型号、所属租户、固件版本、在线状态、故障记录、日志与监控

7.5 动作创建/编辑器（原子动作组合器）

内部平台「动作库」的自定义动作编辑器与租户平台（第 15 章）设计思路一致，并在轨道模型上进一步优化：右侧按原子动作自动生成同名轨道、支持自定义动作效果预览、原子动作属性支持幅度/速度/时间三个维度（速度与时间互为变量）。详细说明如下：

7.5.1 动作基本信息

字段类型说明
动作名称文本自定义动作名称
位置分类下拉头部 / 躯体 / 耳朵 / 全身
动作图标图标选择器支持选择素材库里的动作图标
描述文本动作用途说明

7.5.2 原子动作库

位置原子动作数量
头部点头、摇头、摆头、低头、抬头、左转头、右转头7个
躯体站立、下蹲、站起、蹲起4个
耳朵左耳天线角度、右耳天线角度2个

7.5.3 多轨道时序图（原子动作同名轨道）

编辑器采用「左侧原子动作库 → 右侧同名轨道」的映射设计：

  • 左侧列出当前位置（头部 / 躯体 / 耳朵 / 全身）下的全部原子动作；
  • 右侧自动生成与每个原子动作一一对应、并以原子动作名称命名的轨道（例如"点头""摇头""左耳天线角度"各占一条独立轨道）；
  • 从左侧拖拽某原子动作，落到其同名轨道上即可编排；空轨道显示"拖拽「动作名」到此轨道"提示；
  • 不同原子动作轨道之间可并线同时执行，同一原子动作轨道内的多个动作按顺序执行（互斥）。

7.5.3.1 原子动作属性配置（幅度 / 速度 / 时间）

点击时序轨道上的单个原子动作块，可在右侧属性面板设置三个维度：

维度范围说明
幅度0–100动作幅度，颗粒度 1% 可调；修改幅度会按当前速度重新计算时长
速度0–100动作速度，颗粒度 1% 可调
时间0.5–20 秒单个原子动作的执行时长，支持直接输入
🔁 速度与时间互为变量
  1. 调整速度时，系统按公式自动输出时间（时长 = 0.5 + 幅度×0.025 + (100−速度)×0.02）；
  2. 调整时间时，系统按同一公式反向求解，自动变化速度（速度随幅度与设定时长联动，并钳制在 0–100 内）；
  3. 幅度作为独立维度，修改幅度会按当前速度重新计算时长；
  4. 三者联动，确保任一维度调整后时长与速度始终保持一致。

7.5.3.2 自定义动作效果预览

编辑器提供实时效果预览能力。创建 / 编辑动作弹窗内设有「效果预览」显示区域：在创建过程中，该区域随原子动作的拖入、编排及幅度 / 速度 / 时间调整自动实时刷新，以只读时序图形式展示动作组合效果，便于边编辑边校验。此外，也可点击弹窗底部「👁 预览」按钮，以独立弹窗查看完整预览；或从动效库列表的"预览"入口查看已保存动作的时序图。

🟧 轨道规则
  1. 右侧轨道由左侧原子动作自动生成，轨道名称即原子动作名称，无需手动添加/删除轨道
  2. 不同原子动作轨道的原子动作可并线同时执行
  3. 每个原子动作可设置幅度（0-100）、速度（0-100）、时间（0.5-20秒），颗粒度1%可调
  4. 时序图横轴为时间轴（秒），总时长取所有轨道中最大的起始+时长
  5. 同一原子动作轨道内的多个动作按顺序执行（互斥）
  6. 不同原子动作间有互斥关系，具体互斥逻辑待梳理后再同步

7.5.4 操作流程

1
点击"自定义动作" → 打开编辑器弹窗
2
填写动作名称、选择位置、选择图标、填写描述
3
从原子动作库拖拽原子动作到时序轨道
4
点击原子动作块，设置幅度、速度、时间（速度与时间互为变量：调速度自动输出时间，调时间自动反算速度）
5
时序图实时显示时间轴和块位置
6
保存 → 自定义动作出现在动作库列表
7
支持编辑已有自定义动作
8
支持删除自定义动作

7.6 发布与同步逻辑

1
创建：新建动作，进入"草稿"状态，租户不可见
2
编辑：在草稿状态下编辑原子动作组合，修改不影响已发布版本
3
发布：点击"发布"后状态变为"已发布"，可被同步给租户
4
再编辑：已发布的动作再次修改后，需重新发布并同步
5
同步：点击"同步"选择目标租户（指定租户或全部租户），动作下发到租户平台
6
租户引用：租户在自有动作库中查看已同步的平台动作，可在脚本编辑器中引用
草稿与已发布的隔离：草稿状态下租户不可见，编辑中的修改不会影响已发布的版本。点击"发布"后再次修改，需重新发布并同步。

7.7 底部说明

平台动作库：管理员创建的原子动作组合可发布给租户使用。发布后状态变为"已发布"，通过"同步"动作可将动作下发给指定租户或全部租户，租户收到后可在自有动作库内引用。

9.9 审核完整流程

1
上传：内部运营或租户在素材库上传素材/知识库文档
2
AI初审：系统自动进行内容安全检测，命中风险模型则标记"不通过"
3
通过处理：AI审核通过 → 素材直接转为"可用"状态，可在脚本中引用
4
转人工：AI审核不通过 → 自动流转至人工审核队列，状态变为"待人工审核"
5
人工复审：审核员查看AI检测结果、内容预览（含AI标记）、政治审核要点，填写审核意见
6
通过/驳回：通过 → 素材转为"可用"；驳回 → 素材标记"不可用"，通知上传方

13. 业务规则与权限体系

13.1 内部平台 vs 租户平台权限对比

运行任务只读监控，不可编辑/下发创建/编辑/下发/执行任务
素材库上传素材（需审核）上传素材（需审核）+ 引用
动作库创建/发布/同步动作给租户查看/引用已同步的平台动作
智能体只读查看跨租户智能体创建/编辑智能体、知识库、声纹

13.2 审核流程规则

规则1：AI初审自动执行
所有内部和租户平台上传的素材（图片、表情包、音视频）及知识库文档，上传后自动进入AI审核队列，无需人工触发。
规则2：AI通过直接可用
AI审核通过的内容直接转为"可用"状态，可在脚本/知识库中引用，无需人工干预。
规则3：AI不通过转人工
AI检测命中风险模型的内容，自动流转至人工审核队列，状态变为"待人工审核"。
规则4：人工审核结果
人工审核通过 → 素材转为"可用"状态；人工审核驳回 → 素材标记为"不可用"，通知上传方。
规则5：素材删除不影响已有脚本
素材被删除后，与该素材相关的运行脚本仍可正常使用。

13.3 动作库发布与同步规则

规则1：草稿隔离
草稿状态下租户不可见，编辑中的修改不会影响已发布的版本。
规则2：发布后可同步
动作状态为"已发布"后，才能执行同步操作，将动作下发给指定租户或全部租户。
规则3：再编辑需重新发布
已发布的动作再次修改后，需重新发布并同步，租户侧才能获取最新版本。
规则4：同步范围
同步可选"指定租户"或"全部租户"，同步范围字段显示"未同步 / 部分租户 / 全部租户"三态。

13.4 租户生命周期规则

规则1：设备必须隶属租户
添加设备时必须选择所属租户，设备不能脱离租户独立存在。
规则2：停用租户阻断任务
停用租户后，该租户下设备将无法接收新任务。
规则3：租户账号内部创建
租户账号由内部平台统一创建，关联至具体租户，用于租户侧平台登录与日常运营。

13.5 运行任务只读规则

规则1：只读约束
内部平台运行任务页不支持编辑、暂停或下发执行任何任务，仅用于全局监控与排查。
规则2：跨租户筛选
支持按所属租户筛选任务，查看各租户的任务执行情况。

13.6 RBAC权限模型

维度控制对象配置方式
数据权限设备范围全部设备（跨租户全局）/ 指定设备（按SN多选）
功能权限功能点按模块分组勾选（设备管理 / 内容运营 / 系统管理）

生效逻辑：数据权限与功能权限取交集后生效。数据权限控制"能看到哪些设备"，功能权限控制"能操作哪些功能"。
