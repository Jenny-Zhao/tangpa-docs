1. 产品总览

1.1 产品定位

镋钯租户管理平台是镋钯机器人RaaS（Robot as a Service）平台的租户端Web管理系统。面向文旅景区、科技馆展厅、商业综合体等B端租户用户，提供设备管理、任务编排与下发、脚本编辑、素材管理、智能体配置、知识库管理等全链路运营能力。

核心价值：租户无需管理机器人运层技术，通过可视化界面即可完成机器人运动剧本编排、任务下发执行、内容运营管理，实现"零代码"机器人运营。

机型支持：

  • 镋钯基础版
  • 镋钯激光雷达版

4.2 同步至设备校验逻辑（核心 · 第一步）

🟧 同步至设备校验规则（validateAndDispatch）

当用户点击"同步至设备"按钮时，系统执行以下校验：

  1. 校验1 · 设备在线校验：遍历所有目标设备，检查是否有设备处于"故障"或"离线"状态
    • 存在故障/离线设备 → 同步失败，Toast提示"同步失败：目标设备XXX处于故障/离线状态，无法接收任务"
    • 全部设备正常 → 进入下一步
  2. 校验2 · 脚本任务虚拟仿真校验（仅脚本任务）：脚本任务在同步前必须先执行虚拟仿真校验，无论校验通过与否都会弹出「虚拟仿真校验结果」弹窗，展示仿真结果详情，用户可抉择：
    • 仿真通过 → 弹窗显示"✅ 校验通过"，用户可点击「继续同步」完成同步，或点击「暂不同步」取消；
    • 仿真未通过（存在风险）→ 弹窗显示"⚠️ 校验未通过（存在风险）"及风险说明，用户可点击「带风险继续同步」（仍同步但带风险），或点击「暂不同步」取消。
  3. 同步成功：Toast提示"同步成功：任务「XXX」已同步至N台设备"，任务状态从"待同步"变为"已同步"，操作按钮从"同步至设备"变为"立即执行"

4.3 立即执行校验逻辑（核心 · 第二步）

🟧 立即执行校验规则（validateExecuteScript）

当用户点击"立即执行"按钮时，系统依据机器人当前模式与任务优先级规则进行校验：

  1. 查找首个有效设备：在目标设备列表中找到第一个处于remote/script/follow/advert模式的设备
  2. 无有效设备（全部故障/离线） → 校验不通过，展示"目标设备均处于故障/离线状态，无法下发执行指令"
  3. 有效设备存在，根据其当前模式匹配规则：
    • 遥操模式（规则2）：✅ 允许下发，机器人接收云端执行指令后，自动切换为任务状态，执行队列第一个任务（被新下发的任务排在最前）
    • 脚本任务模式（规则3）：❌ 拒绝下发，机器人处于独占模式，不支持接收新任务执行指令，提示"等待当前的脚本任务结束后再下发"
    • 跟随任务模式（规则4）：
      • 下发广告互动任务 → ✅ 允许下发，跟随任务与广告互动任务叠加执行
      • 下发脚本任务/跟随任务 → ❌ 拒绝下发，仅支持接收广告互动任务
    • 广告互动任务模式（规则5）：✅ 允许下发，机器人支持接收任意任务指令，接收后立即切换执行新任务
  4. 校验结果展示：弹出校验结果弹窗，显示任务名称、任务类型、目标设备、机器人当前模式、违规规则、校验结论（通过/拒绝）及详情原因

📌 「立即执行」运行时行为（本期明确）：

  • 机器人进入任务状态时，默认进入任务态，手柄上显示对应标识信息（如红灯亮起）；
  • 任务执行结束后，机器人自动回到遥操模式；
  • 任务执行过程中，遥控器急停（E-Stop）始终生效且为最高优先级，可随时中断任务。

5.3 脚本复制

支持对已创建的脚本进行复制，点击列表操作列"复制"按钮后弹出复制弹窗，支持自定义重命名，确认后生成一条新的脚本。
字段类型说明
原脚本文本（只读）自动回填被复制脚本的名称，不可编辑
新脚本名称文本输入 | 必填默认回填"原脚本名-副本"，支持自定义重命名；为空时不可确认
🟧 复制规则
  1. 复制后生成一条全新的脚本记录，完整继承原脚本的分组、适用型号、时间轴与动作编排内容
  2. 新脚本初始状态为"编辑中"，需重新校验发布后才可被任务引用
  3. 新脚本名称允许与原脚本重名（系统以脚本ID区分），但建议用户自定义区分
  4. 任意状态（可用/编辑中/不可用）的脚本均支持复制

6.3 时间轨道结构

每个设备包含以下轨道，按机型能力决定可用轨道：

轨道标签说明互斥规则
头部轨道⭐ 头部头部动作编排同一时间点仅允许1个头部动作
躯体轨道🦵 躯体躯体动作编排同一时间点仅允许1个躯体动作
耳朵轨道👂 耳朵耳朵动作编排可与任何其他轨道叠加
音视频轨道🎵 音视频素材内容（音频/视频）同一时间点仅允许1段音频或视频
交互轨道🖼 交互素材内容（图片/表情）可与音视频轨道叠加
🟧 轨道互斥规则
  • ✅ 头部、躯体、耳朵动作可同时分别存在一个
  • ✅ 耳朵动作可与任何其他轨道叠加

6.5 动作执行规则

🟧 动作执行规则
  1. 姿态保持（规则1）：动作执行完毕后保持最后一帧姿态，不自动回正；如需回正，需显式添加回正动作。多个连续动作之间直接衔接，以上一动作末帧为起点继续执行下一动作。
  2. 组合动作缩放踩点（规则2）：支持自定义组合动作在轨道上以缩放编辑方式自动同比例调整动作时间，以满足音乐节拍匹配、精准踩点需求；但每个原子动作的执行时间不得小于该动作对应关节运动能力的下限。
  3. 自定义动作二次编辑（规则3）：自定义动作支持二次编辑且不影响历史脚本：每次修改保存后生成新 UUID，已有脚本引用的仍为旧版本快照，保证历史脚本执行不受影响。

14. 业务规则与状态机 P0

14.1 运行任务执行指令状态机规则

🟧 详情说明：运行任务执行指令状态机规则

以下规则与下发验证配套使用（依据任务优先级与机器人当前状态）：

  1. 本体任务排序：根据任务优先级、最新下发的任务，排序在最前面
  2. 规则2 - 遥控模式：当机器人处于遥控模式，本体接收到从云端（租户Web平台 & App）下发的所有任务指令时，自动调整状态为任务状态，并执行队列第一个任务
  3. 规则3 - 脚本任务独占：当机器人处于任务状态，且当前执行的是脚本任务，则机器人处于独占模式，不支持接收新任务执行指令
  4. 规则4 - 跟随+广告互动叠加：当机器人处于任务状态，且当前执行的是跟随任务，则机器人仅支持接收广告互动任务执行指令，接收后跟随任务和广告互动任务叠加执行
  5. 规则5 - 广告互动任务可打断：当机器人处于任务状态，且当前执行的是广告互动任务，机器人支持接收新任务指令，接收后立即切换执行新任务

14.2 机器人任务间关系

镋钯机器人任务关系：当前结构（模式-任务-切换）→ 优化后结构（任务模式聚合）
机器人当前模式可接收的任务类型行为适用规则
遥控模式脚本/跟随/即时自动切换为任务状态，执行队列首任务规则2
脚本任务（独占）无拒绝所有任务规则3
跟随任务仅广告互动任务跟随+广告互动叠加执行规则4
广告互动任务脚本/跟随/广告互动立即切换执行新任务规则5

用户可自行编排复合动作，通过组合原子动作到时序图，定义每个原子动作的幅度、速度和时间，实现自定义动作的创建、编辑和删除。编辑器采用同名轨道设计（左侧每个原子动作对应右侧一条以该动作命名的轨道），并在弹窗内提供效果预览与速度↔时间自动互算。脚本编辑器和PRO版共用同一个编辑器弹窗。

15.3 同名轨道时序图（原子动作 → 轨道）

编辑器右侧时序图按"左侧原子动作"自动生成对应轨道：左侧有几个原子动作，右侧即有对应该原子动作的几条轨道，每条轨道名称即为原子动作名称。从左侧原子动作库拖拽原子动作到其同名轨道即可编排，不同原子动作轨道可同时执行（并线），同一原子动作轨道内按顺序执行（互斥）。
位置对应的原子动作同名轨道
头部点头1次、摇头1次、摆头1次、低头后保持、左转头保持、右转头保持（各 1 条同名轨道）

全身头部 + 躯体 + 耳朵全部原子动作的同名轨道
🟧 轨道与属性规则
  1. 每个原子动作对应一条以原子动作名称命名的轨道，左侧原子动作增减时右侧轨道自动增减
  2. 不同原子动作轨道之间可并线同时执行；同一原子动作轨道内按时间顺序排列（互斥）
  3. 每个原子动作块可配置三个属性维度：幅度（0-100）、速度（0-100）、时间（秒）
  4. 🔁 速度与时间互为变量：调整速度后自动输出时间，调整时间后自动反算速度（时长 = f(幅度, 速度) 自动计算）
  5. 时序图横轴为时间轴（秒），总时长取所有轨道中最大（起始 + 时长），最小 5 秒
  6. 编辑器内提供实时效果预览：创建过程中随编排、幅度 / 速度 / 时间自动刷新；点击"预览"按钮打开实际动作效果预览弹窗——以机器人预览屏逐帧展示真实姿态（幅度影响幅度、速度影响节奏），并列出动作序列与总时长，而非仅展示时间轴

15.4 操作流程

自定义动作创建 / 编辑流程
  • ➕ 点击"自定义动作" → 打开编辑器弹窗
  • 📝 填写动作名称、选择位置、选择图标、填写描述
  • 🎯 从原子动作库拖拽原子动作到其同名轨道（右侧轨道随左侧原子动作自动生成）
  • ⚙️ 点击原子动作块，设置幅度、速度、时间（速度↔时间自动互算，时长自动计算）
  • 👁 编辑器内实时效果预览，或点击"预览"打开实际动作效果预览（机器人预览屏逐帧展示姿态，可播放）
  • ✅ 保存 → 自定义动作出现在左侧动作库列表
  • 🔄 支持编辑已有自定义动作（点击列表中的编辑按钮重新打开编辑器）
  • 🗑 支持删除自定义动作
⚠️ 数据隔离：用户自定义动作支持修改；修改动作定义后不会影响已编排到脚本中的该动作副本——脚本在引用自定义动作时即生成独立快照，二者互不干扰。
